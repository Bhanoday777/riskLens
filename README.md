# 🔍 RiskLens

### Human-in-the-Loop (HITL) AI Risk Analysis System

RiskLens is a Human-in-the-Loop (HITL) AI system built using LangGraph for analyzing AI-generated decisions through risk scoring, confidence evaluation, and human oversight. The project focuses on improving transparency, interpretability, and trust in AI-assisted decision-making workflows.

---

## 📖 Overview

Modern AI systems often make decisions that require human supervision in high-risk scenarios. RiskLens demonstrates how Human-in-the-Loop workflows can be used to monitor AI decisions, evaluate confidence levels, assess risk, and analyze human intervention patterns.

The system simulates AI-generated approval and blocking decisions and provides analytical insights through risk evaluation and decision monitoring.

---

## ✨ Key Features

* Human-in-the-Loop (HITL) decision workflow
* AI approval and blocking decision analysis
* Risk score evaluation and categorization
* Confidence score monitoring
* Human intervention tracking
* Explainable AI analytics
* Decision outcome visualization
* AI behavior monitoring and reporting
